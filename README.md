# 🏨 Hostel Booking System  
A complete, production‑ready hostel booking platform with real‑time bed availability, booking engine, admin dashboard, email notifications, calendar sync, and Excel export.

This project includes:

- Full frontend (HTML, CSS, JS)
- Full backend (Node.js + Express)
- MySQL database
- Admin dashboard
- Booking engine
- Bed blocking system
- Excel export system
- Email confirmation system
- Google Calendar sync
- Nginx deployment configuration

---

## 🚀 Features

### 🛏️ Booking System
- Real‑time bed availability  
- Bed selection  
- Guest details form  
- Booking confirmation  
- Automatic email notifications  
- Google Calendar event creation  

### 🧑‍💼 Admin Dashboard
- Login (JWT authentication)  
- View all bookings  
- Filter by date, room, status  
- Add manual bookings  
- Cancel bookings  
- Block beds (maintenance/cleaning)  
- Export bookings to Excel  

### 📄 Frontend Pages
- Homepage  
- Rooms page  
- Booking page  
- Admin login  
- Admin dashboard  

### 📦 Backend API
- `/api/rooms`
- `/api/availability`
- `/api/book`
- `/api/admin/login`
- `/api/admin/bookings`
- `/api/admin/bookings/add`
- `/api/admin/bookings/cancel`
- `/api/admin/block`
- `/api/admin/export/excel`
